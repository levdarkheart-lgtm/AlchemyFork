## Source-confirmed inherited findings for mandatory defect registration

No register edits made by this agent. Suggested separate records or a clearly scoped malformed-mesh record with retained subcases:

- Truncated skin weight influence can read beyond its binary array (`llvolume.cpp:2616–2632`; `a60d81a111`).
- Weight array ending before all vertices leaves remaining weights uninitialized (`llvolume.cpp:2648ff`; `efd275c864`).
- Mesh decode has no face/index-count work caps before allocation (`llvolume.cpp:2379/2413`; `9636b1190d`, `92f6d3bf58`, `2f23dbcf3e`). Existing compressed/unzip caps do not bound indices/face objects tightly enough.
- Quaternion nonfinite normalization can emit NaN/zero shared transforms (`llquaternion.h:526–577`; `6a0a982f5f`).
- Gained mesh faces inherit last placeholder face's material/TE instead of already received per-face data (`LLPrimitive::setNumTEs`, `LLViewerObject::setNumTEs`; `93c320b7eb`).
- Octree insert child overflow bypasses own capacity; geometry omission attribution should be kept source-level until reproduced (`lloctree.h`; `6ff9523744`).

Missing optional attributes/copy handling (`5fee21f66e`, `fd02953f7f`, `4d4d9f875f`) is also worth preserving in final geometry stack, but those patches are written against a replaced cache/remap path. Existing copy uses allocated-but-unwritten streams; diagnose its currently reachable loader consumers before declaring a separate current incident.
