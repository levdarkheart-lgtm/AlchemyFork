# Architecture decisions

Create a compact numbered `NNNN-title.md` only for choices that affect persistent rendering semantics, dependency strategy, product constraints, user-facing functionality or measured performance. Include date, evidence/source SHA, context, alternatives, decision, tradeoffs and reversal criteria. Do not create ADRs for routine syntax changes.

Product constraint changes require an explicit owner decision, not an agent-only ADR. A perf optimization needs baseline/candidate evidence before being described as faster.
